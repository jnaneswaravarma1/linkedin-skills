# Developer Profile Builder

## What this skill does
Builds a strong developer profile that
gets noticed by hiring managers and
senior developers.
Covers GitHub, LinkedIn, and personal bio.
Shows draft first — waits for approval.

---

## Step 1 — Current profile
Ask: "Where do you want to optimize?
1. GitHub profile README
2. LinkedIn headline and about
3. Personal bio (portfolio/website)
4. All three"

Wait for answer.

---

## Step 2 — Get their info
Ask all at once:
"Tell me:
1. Your current role or title
2. Your top 3 technical skills
3. What you are building or learning now
4. Your biggest achievement so far
5. What kind of work you want next"

Wait for answer.

---

## If option 1 — GitHub README

Write in this format:
Hi, I'm [Name] 👋

[One line that says who you are and what you build]

What I do

[2-3 sentences on your focus and skills]

Currently
🔨 Building: [current project]
📚 Learning: [current learning]
🎯 Goal: [what you're working toward]
Tech stack

[list of main technologies]

Connect

[LinkedIn / portfolio / email]

---

## If option 2 — LinkedIn

Write headline in this format:
[Role] | [Top skill] + [Top skill] | [What you build]

Write About section:
[Hook — one strong sentence about what you do]

[What you've built or shipped — specific]

[What you're working on now]

[What you're looking for next]

[Call to action — connect / message / view work]

---

## If option 3 — Personal bio

Write in this format:
[Name] is a [role] who [what you build and for whom].

[One specific achievement with numbers if possible]

Currently [what you're building or learning].

[Where to find their work]



---

## Rules
- Always use specific details — no vague claims
- Numbers beat adjectives always
- Show draft — wait for approval
- Ask: "Want this more formal or more casual?"
- Never use buzzwords: "passionate", "ninja",
  "rockstar", "guru", "leverage"
