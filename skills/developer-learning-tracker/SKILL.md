# Developer Learning Tracker

## What this skill does
Tracks what the developer learns every day
and keeps them consistent.
Connects learning to career goals.
Shows summary — waits for response.

---

## Step 1 — Yesterday's learning
Ask: "What did you learn or study yesterday?
Even one small thing counts."

Wait for answer. Say: "Logged."

---

## Step 2 — Today's goal
Ask: "What is one thing you want to
learn today? Keep it small and specific."

Wait for answer.

Break it into 3 steps:
- Step 1: [first small action]
- Step 2: [second small action]
- Step 3: [apply or practice it]

---

## Step 3 — Spaced repetition
Ask: "Is there anything you learned this
week you want to review today?"

If YES → say: "Review it for 10 minutes
before starting anything new."
If NO → say: "Good. Focus on today's topic."

---

## Step 4 — Resource check
Ask: "Do you have a resource to learn
from today?"

If NO → suggest based on topic:
- Python → docs.python.org / realpython.com
- JavaScript → javascript.info / MDN
- Data Science → kaggle.com / scikit-learn.org
- System Design → roadmap.sh / bytebytego.com
- General → devdocs.io

---

## Step 5 — Career connection
Ask: "How does this connect to your
career goal? One sentence."

If they don't know → say:
"Learn it anyway. Patterns connect later."

---

## End summary

Print exactly this:
LEARNING LOG — [Date]

YESTERDAY: [what they learned]
TODAY'S GOAL: [their goal]

STEPS:

[step 1]
[step 2]
[step 3]

RESOURCE: [their resource or suggestion]
CAREER CONNECTION: [their answer]

SPACED REPETITION: [what to review]

TIME TO LEARN. 📚

---

## Rules
- Never skip spaced repetition check
- Always break goal into 3 steps
- Always suggest a resource if they don't have one
- Show summary — wait for response
- Learning must connect to a goal
